Full-Stack Web App · LLM + Deterministic Logic

gaugeCalc

2026 — present
Live site ↗ View repo ↗

A tool for knitters and crocheters that recalculates a PDF pattern's stitch and row counts for a different gauge and stamps the corrected numbers directly onto the original pattern. Claude parses the raw pattern text into structured gauge and section data, deterministic code handles the rescaling and rounding math, and a React frontend talks to an Express backend that stamps the corrected values back onto the PDF. Knitting and crocheting are genuine hobbies of mine, this started as a way to solve my own gauge-swapping headaches, not a demo topic.

Still working out edge cases: stamp alignment drifts on multi-column patterns, and increases and decreases aren't handled yet.

LLM Prompt Design · Team of 3 · CHI Award Recipient

LinguaGemma

Advanced Projects in Interactive Media — Sept 2023 – May 2024
View repo ↗ View publication ↗

An LLM-based chatbot with two distinct prompt-driven teaching logics, benchmarked against each other in a controlled study.

A chatbot's "personality" is really just its prompt-level rules, and different rule sets should produce measurably different outcomes — so we built two prompt logics and compared them directly.

Designed and hosted the chatbot locally, developing separate prompt logic for a growth-mindset agent and a fixed-mindset control. Assessed impact using word-search recall tests and thematic and semantic analysis of chat logs. The growth-mindset logic demonstrated higher comfort, confidence, and engagement, winning the 2024 CHI undergraduate research competition. Collaborated with two classmates, coordinating study design and project timeline.

Published as "Exploring LLM-based Chatbot for Language Learning and Cultivation of Growth Mindset" at CHI EA '24 (DOI: 10.1145/3613905.3648628).
